# Screenshots

One folder per house, plus `app/` for interface states. File names say what is shown: `layout-0`, `-1`, `-2` is the floor index (0 = EG), `phone-320` / `phone-390` a phone screen width, `day` / `night` the theme, `folded` the stacked house, and `*-card` a room or space dialog. `photo-*` and `*-exterior-*` images are exterior reconstructions.

To find a picture, scan this list instead of opening images.
